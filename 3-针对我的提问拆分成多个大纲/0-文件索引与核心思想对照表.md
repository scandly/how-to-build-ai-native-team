# 5-针对我的提问拆分成 22 个大纲 —— 文件索引与核心思想对照表

## 阅读建议

这是整个知识体系的核心骨架。建议先读前言建立术语共识，再按大纲顺序（1→18）逐层深入，从基础契约协作到运行时韧性，再到进化控制、资源限制、扩展性，最后到伦理底线。每一条大纲都是后续"问题映射"目录的理论基础。
